1. Purpose and scope

AllPrime is a primer design tool developed for use within a laboratory. It does not interpret patient data, does not produce a diagnostic result, and makes no assessment about any individual.

This software is not an in vitro diagnostic (IVD) medical device and has not undergone any conformity assessment for that purpose.

2. Validation is the user's responsibility

Primers produced by this software should be experimentally validated by the user's laboratory before any diagnostic use; the software has not been validated for that purpose. This is a warning, not a condition of use.

  • The specificity scan and common-variant (dbSNP) avoidance are supporting checks; they do not replace experimental validation.
  • Results depend on the reference genome and annotation versions in use. GRCh37 (hg19) and GRCh38 (hg38) coordinates differ; the user must confirm which build a reported coordinate belongs to.
  • Transcript selection relies on the user's input. The transcript reported (NM_ accession and version) is the user's responsibility.

5. Data sources

  • Reference genome sequences — Ensembl (GRCh37 / GRCh38)
  • Transcript and exon structure — UCSC refGene (derived from NCBI RefSeq)
  • Canonical transcript flags — NCBI MANE
  • Common variants — UCSC snp151Common (derived from NCBI dbSNP b151)

All computation runs on the local machine. If no local genome is configured, the Ensembl REST API may be used to fetch sequence; in that case a genomic coordinate is queried. If the transcript table is not configured either and the position is given as a gene symbol, the gene symbol is queried as well. No patient data is transmitted.
